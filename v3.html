Main result (steps 7–10)
  • The report does not follow the swap. On the 184 main situations where the answer stayed word-for-word identical under both swap and control, the self-report named C in 9/184 vs 10/184 situations (difference -0.5 pp [-1.6, +0.0], exact McNemar p = 1). Recognition is identical across conditions: C chosen 58/368 times under the swap and 58/368 under the control.
  • The edited prompt state barely reaches the report at all. 225 of 233 swap reports are character-for-character identical to the no-edit report; so are 219/222 control reports. The second-choice question, injection and edited third-person prediction are equally flat. By the pre-registered interpretation table this is the row “edit-shift holds; report does not follow”: the report does not read this state, at least not through these edited positions.
  • The same directions do move reports when placed next to the question. The late edit (same V and α, applied at the ~41 tokens of the appended question, no prompt edit) makes the report name C in 80/184 vs 10/184 situations (+38 pp [+30, +46], p = 5e-16). The timing contrast (early − late) is -39 pp: the opposite of what a report reading the earlier state predicts, and the pattern the protocol reads as a general late bias.
  • The manipulation check replicates. On the main set the swap raises log p(C) − log p(B) at the answer’s name more than the control in 82% of instrument situations (mean +0.40 nats [+0.32, +0.48]) and 73% of country situations (+0.75 [+0.50, +1.00]); the country share is just under the 75% development threshold. The effect is small: C overtakes B in 1% / 9% of situations.
  • Without an edit, self-report is no better than another-instance prediction. Free naming matches the top lens competitor in 52/307 self-reports vs 50/307 context predictions; recognition 198/614 vs 192/614. β_L (conditional logit on corrected scores) is +0.01 ± 0.11 for self and +0.26 ± 0.11 for context. When allowed to abstain, the model abstains on itself (295/307) far more than on another instance (159/307).
  • Caveat on power. The edit is small where the report is produced: even the norm-matched random control changes only 3/222 reports. So the experiment shows the report is insensitive to this answer-time state at an edit size that keeps the answer intact, not that no larger edit could reach it.
  • Dose (α = 1, 2, 4) does not change the conclusion. The prompt edit never moves the report: C named 10 vs 11/259, 10 vs 10/235, 9 vs 10/184. The late edit grows with α: +7 pp, +17 pp, +38 pp. So do the edit-shift at the answer (+0.14, +0.28, +0.58 nats) and the share of changed answers. Every report measure is flat at every strength; only the late edit and the next-token odds respond to dose.

8Swap stage: reports (steps 8–10)

For each eligible situation we build four prompt states at the frozen setting (blocks 48–53, last five prompt tokens, α = 4): no edit, swap (B↔C), control (norm-matched random direction orthogonal to B and C) and injection (raise C only). The model regenerates its answer from each state; only states whose answer is token-for-token identical are kept. From each kept state, in separate branches with the answer in context, we ask the competitor question (free naming, recognition in two menu orders), the second-choice question and, for no edit, the remaining question variants. Two further conditions use swap and control only: the late edit (no prompt edit; the same edit at every token of the appended competitor question) and edited third-person prediction (another-instance prediction with the edit at the last five tokens of the quoted request). “Follow” means the report names C.
